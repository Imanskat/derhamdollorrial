# محاسبه‌گر بهای تمام‌شده واردات لوازم آرایشی
### دبی ← بندرعباس ← تهران · درهم / دلار / ریال

ابزاری برای محاسبه اینکه هر قلم کالای آرایشی وارداتی، **از لحظه خرید در دبی تا رسیدن به قفسه در تهران، واقعاً چقدر تمام می‌شود** — و اینکه با قیمت فروش فعلی چقدر سود می‌ماند.

| فایل | چیست |
|---|---|
| `index.html` | داشبورد وب. فایل را در هر مرورگری باز کنید — نیازی به نصب چیزی نیست. |
| `بهای-تمام-شده-واردات.xlsx` | همان مدل به‌صورت فرمول‌های زنده اکسل. |
| `build_workbook.py` | اسکریپتی که فایل اکسل را می‌سازد. |

هر دو فایل **یک مدل محاسباتی یکسان** دارند و اعدادشان با هم مطابقت داده شده است.

## مسیر هزینه‌ای که مدل می‌کند

```
دبی                بندرعباس                              تهران
 │                     │                                   │
 خرید به درهم ──حمل دریایی──► گمرک ──حمل جاده‌ای──► انبار ──► فروش
                              حقوق ورودی
                              ارزش افزوده
```

**بهای تمام‌شده هر واحد** از این اجزا ساخته می‌شود:

| جزء | مبنا |
|---|---|
| ارزش کالا (FOB) | قیمت درهمی × تعداد × نرخ درهم |
| کرایه دریایی | وزن × کرایه هر کیلو (درهم) × نرخ درهم |
| بیمه | درصدی از ارزش کالا |
| **ارزش CIF** | کالا + کرایه + بیمه |
| حقوق ورودی گمرک | درصدی از CIF |
| حمل داخلی | وزن × کرایه هر کیلو (ریال) |
| سهم از هزینه‌های مقطوع | ترخیص، انبارداری، مجوز — سرشکن‌شده بر مبنای وزن یا ارزش |
| هزینه‌های جانبی | برچسب اصالت، بسته‌بندی و مانند آن، برای هر واحد |

ارزش افزوده گمرک روی `CIF + حقوق ورودی` حساب می‌شود و **به‌صورت پیش‌فرض جزو بهای تمام‌شده نیست** — چون اگر مؤدی ثبت‌نام‌شده باشید با ارزش افزوده فروش تهاتر می‌شود. اگر ثبت‌نام مالیاتی ندارید، این گزینه را عوض کنید تا جزو هزینه حساب شود.

قیمت فروش را **با ارزش افزوده** (همان قیمت قفسه) وارد کنید؛ ابزار خودش آن را کنار می‌گذارد تا سود واقعی به دست آید.

## چهار عددی که واقعاً به درد مدیرعامل می‌خورد

1. **بهای تمام‌شده هر واحد** — عددی که هر تصمیم قیمت‌گذاری باید بالای آن باشد.
2. **نرخ درهم سربه‌سر** — چون بخشی از هزینه‌ها ارزی و بخشی ریالی است، بهای تمام‌شده به‌صورت خطی به نرخ درهم وابسته است (`بهای تمام‌شده = A × نرخ + B`). حل این معادله نرخی می‌دهد که در آن سود صفر می‌شود. فاصله نرخ امروز تا آن نرخ، **حاشیه امنیت ارزی** شماست.
3. **بازده سالانه‌شده** — سود ۴۰٪ روی محموله‌ای که ۶۰ روز می‌ماند با همان ۴۰٪ روی محموله‌ای که ۶ ماه می‌ماند یکی نیست. این ستون هر دو را قابل مقایسه می‌کند.
4. **سود واقعی پس از جایگزینی محموله** — مهم‌ترین عدد در اقتصاد تورمی: سود دفتری با نرخ روز خرید حساب می‌شود، اما محموله بعدی را با نرخ امروز می‌خرید. اگر ریال ضعیف شده باشد، بخشی از «سود» فقط برای خرید دوباره همان مقدار جنس کافی است.

## ⚠️ نکته حیاتی درباره نرخ ارز

سرویس‌های عمومی ارز (Google، exchangerate، frankfurter و مانند آن‌ها) نرخ **رسمی** ریال را می‌دهند، نه نرخ **بازار آزاد**.

اگر بهای تمام‌شده را با نرخ رسمی حساب کنید، عدد **چند برابر کمتر از واقعیت** درمی‌آید و کالا را زیر قیمت تمام‌شده می‌فروشید. این ابزار فقط نرخ بازار آزاد را مبنا می‌گیرد.

**درباره به‌روزرسانی خودکار:** دکمه «به‌روزرسانی خودکار نرخ» منابع نرخ آزاد (نوسان، TGJU، آلان‌چند) را به ترتیب امتحان می‌کند و اگر نرخی شبیه نرخ رسمی برگردد آن را رد می‌کند. اما این منابع رسمی نیستند و ممکن است به‌خاطر CORS، فیلترینگ یا تغییر ساختارشان جواب ندهند — **این مسیر در محیط ساخت این ابزار قابل آزمایش نبود، چون دسترسی شبکه‌اش بسته بود.** بنابراین:

- اگر واکشی خودکار کار کرد، نشانگر سبز می‌شود و منبع و زمان نرخ را نشان می‌دهد.
- اگر کار نکرد، پیام قرمز می‌بینید و باید نرخ را دستی وارد کنید. **آخرین نرخ معتبر ذخیره می‌ماند** و چیزی از دست نمی‌رود.
- مطمئن‌ترین راه، گرفتن کلید API از [navasan.tech](https://navasan.tech) و وارد کردن آن در کادر مربوطه است.

نرخ **دلار به درهم** (۳٫۶۷۲۵) میخکوب است و عملاً تغییر نمی‌کند؛ فقط نرخ ریال است که باید مرتب به‌روز شود.

## استفاده از داشبورد وب

فایل `index.html` را در مرورگر باز کنید (روی موبایل هم کار می‌کند).

- سه بخش ورودی: **نرخ ارز**، **پارامترهای محموله**، **کالاها**.
- واحد نمایش را می‌توانید بین **ریال / تومان / میلیون تومان** عوض کنید.
- همه داده‌ها در همان مرورگر ذخیره می‌شوند (`localStorage`) — **چیزی به هیچ سروری فرستاده نمی‌شود** و دفعه بعد همان اعداد سر جایشان هستند.
- خروجی **CSV** و **چاپ** دارد. حالت تیره هم دارد.

چهار نمودار:

| نمودار | چه می‌گوید |
|---|---|
| ساختار بهای تمام‌شده | هر ستون یک کالا، تفکیک‌شده به کالا / کرایه / گمرک / حمل داخلی / جانبی |
| حاشیه سود هر کالا | آبی سودده، قرمز زیان‌ده |
| حساسیت سود به نرخ درهم | اگر قیمت فروش ثابت بماند، با بالا رفتن نرخ ارز سود کجا صفر می‌شود |
| نرخ درهم سربه‌سر هر کالا | کدام کالا زودتر زیان‌ده می‌شود؛ خط عمودی نرخ امروز است |

## استفاده از فایل اکسل

۱. در شیت **پارامترها** نرخ درهم روز و پارامترهای محموله را وارد کنید.
۲. در شیت **کالاها** ستون‌های `A` تا `I` (زمینه زرد) را پر کنید. تا ۲۵ کالا آماده است و ردیف‌های خالی نادیده گرفته می‌شوند.
۳. شیت **خلاصه** سرمایه لازم، سود، بازده، ریسک ارزی و یک جدول حساسیت را می‌دهد.
۴. شیت **راهنما** توضیح هر بخش را دارد.

قرارداد رنگ‌ها: **آبی روی زرد = ورودی** (فقط این‌ها را عوض کنید) · **سیاه = فرمول** · **سبز = ارجاع به شیت دیگر**.

ستون‌های کمکی `AE` تا `AG` برای حل معادله نرخ سربه‌سر لازم‌اند — می‌توانید پنهانشان کنید اما حذف نکنید.

برای ساخت دوباره فایل اکسل:

```bash
pip install openpyxl
python3 build_workbook.py
```

## اعتبارسنجی

- مدل اکسل (۶۷۷ فرمول) بدون هیچ خطایی محاسبه می‌شود و اعدادش با موتور محاسبه داشبورد وب مطابقت داده شده است.
- بررسی شده که جمع اجزای هزینه دقیقاً برابر بهای تمام‌شده کل است، سهم‌های سرشکن دقیقاً ۱۰۰٪ می‌شود، و بهای تمام‌شده در نرخ سربه‌سر دقیقاً برابر سود در دسترس درمی‌آید.
- پالت رنگی نمودارها با آزمون کوررنگی در هر دو حالت روشن و تیره سنجیده شده است.

## ⚠️ همه اعداد پیش‌فرض، نمونه‌اند

مقادیر اولیه فقط برای نشان دادن نحوه کار ابزارند. پیش از هر تصمیم واقعی این‌ها را تأیید کنید:

- **نرخ ارز** — از صرافی.
- **درصد حقوق ورودی** — از ترخیص‌کار. برای لوازم آرایشی معمولاً بالاست و بسته به ردیف تعرفه فرق می‌کند.
- **هزینه‌های ترخیص و مجوز** — واردات آرایشی و بهداشتی در ایران مجوز و ثبت جداگانه لازم دارد.
- **نرخ ارزش افزوده** و وضعیت ثبت‌نام مالیاتی شرکت.

«بازده سالانه‌شده» فرض می‌کند سرمایه بلافاصله در محموله بعدی به کار می‌افتد؛ در عمل فاصله بین محموله‌ها این عدد را کم می‌کند.
